# Tool 80 srl — Jump in the data flow

Official website for **Tool 80 srl**, a research-driven SME based in Trento, Italy, specialising in multimedia data streaming, MPEG/MPAI standards, and AI-based data coding.

## About

Tool80 carries out research and development in the coding and decoding of multimedia data streams according to MPEG and MPAI standards. The company also brings expertise in generic data streaming across domains including open data, energy data, and genomic data — providing consulting, design, and system integration support across a variety of platforms.

Tool80 is an **Associate Member of MPAI** — the international, non-profit organisation developing standards for AI-based data coding.

## Services

- **Multimedia Data Streaming** — Coding and decoding of multimedia data streams per MPEG and MPAI standards
- **Generic Data Streaming** — Expertise across open data, energy, and genomic data domains
- **Consulting & Integration** — Design and system integration support on a variety of platforms
- **AI Algorithms** — Implementation of AI-based algorithms tailored to data processing needs

## Running Locally

Because the site is fully static, you can open it directly in a browser:

```bash
open index.html
```

Or serve it with any static file server, for example:

```bash
npx serve .
# or
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.
